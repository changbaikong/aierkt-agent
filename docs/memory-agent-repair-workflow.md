# 模型记忆代理修复与验收工作流

日期：2026-10-13。用途：让后续执行者按证据修复，控制付费调用，避免局部通过被误报为整体完成。

本文件是执行工作流，不表示产品已实现。当前 B 未完成，C 真实记忆整链仍未放行；不授权部署、推送或处理生产数据。保留工作区已有修改和历史证据。

## 执行原则

- 模型负责含义、事项关联、认同、期限和纠错；程序负责真实来源、权限、版本、原子提交与防重复。不用字词相似度代替语义判断。
- 每项分别判断：模型理解、实际数据库、后续新会话行为。任一必需项失败，不宣布完成。
- 不确定但有真实依据的内容允许被代理参考并相关追问；格式错误、超时和无依据不能冒充不确定记忆。
- 独立验收从原话制定预期，不从产品回执或模型自评生成答案。失败、漏记、未知及未执行分别记录，不从分母删除。

## 第一步：固定问题与预算

读取最新暂停报告与有关原始证据，确认当前配置、调用入口和工作区状态。先检查实际入口，不猜测接口能力，不输出密钥。

为本轮建立隔离证据目录，记录：问题编号、原话与相关历史、旧记录、预期新内容与状态、期限、预期召回及澄清行为、版本指纹、未解决项。原始输出只追加或另存，不覆盖历史失败。

付费调用分批设上限：首先最多3次能力预检；小批最多12次新模型调用；全部相关小批通过后才允许最终18类各3次。样例次数与模型调用次数分别统计，多轮工具调用不能藏在一个样例内。最终批默认最多324次模型调用，并计入主回答、修正和失败调用。开始前记录调用上限、生成用量上限以及本地可核实的价格；金额无法核实时明确未知，不编造费用。

产物：本轮问题表、预期答案、预算与停止条件。缺少上述产物不得开始大批付费测试。

## 第二步：免费重放，定位失败层

先将保存过的真实错误输出送入隔离解析、保存和召回路径。每个问题先写失败测试并确认失败，再修复。不得为了通过改变原预期。

| 观察 | 优先定位 |
| --- | --- |
| 原话明确，模型理解错误 | 输入背景、代理任务、检索和语义判断 |
| 理解正确，却因字段或引用形式失败 | 输出协议与接收协议 |
| 判断正确，却没写入或重复写入 | 实际入口、事务、版本与恢复 |
| 数据库正确，新会话仍用旧内容 | 召回过滤、排序和上下文消费 |
| 拒写后旧决定仍被当确定现行决定 | 变更依据、待核对状态与纠错闭环 |
| 超时或空输出 | 单次及总预算、推理用量、服务等待；没有证据时不归咎网络 |

产物：可复现失败、定位证据、改动理由。能免费重放定位的问题，不重新付费生成同类输出。

## 第三步：只修一个真实闭环

优先跑通“暂不部署”：代理读取用户原话，主动搜索旧立即执行记录，读取来源和版本，删除助手补出的地点，形成忠实修改方案，持久保存判断，再原子提交。另开会话检查只把新决定当现行内容。

再跑通不确定闭环：保存有依据的疑点 → 新会话检索并标明不确定 → 回答已知部分并最多追问一个相关问题 → 用户回答 → 读取原疑点并纠正 → 新会话使用更新结果。沉默不确认，无关疑点不追问，没有实际发布的问题不能记成已问。

期限按事项拆开：一次请求及当天情绪一天、临时提醒三天、阶段决定到替代或结束、长期事实偏好原则持续。代理判断不确定时标疑点，不能用默认天数冒充明确结论。

产物：两个闭环的原话、代理检索轨迹、判断理由、数据库前后快照和新会话回答。只证明模型调用成功，不算完成本步骤。

## 第四步：变体与有界恢复

同一个修复必须同时验证误存与误拒：换措辞、换主客体、否定反转、同值不同写法、不同事项同数字、短句认同与多项建议、选择与尚未实施、一次请求与阶段约束。同义不生成重复版本。

恢复检查覆盖：无配置、伪造引用、格式修正失败、超时、版本变化、判断持久化后崩溃、提交后崩溃、重启和重复领取。已完成判断重试提交时不再次调用模型；版本变化须重新读取受影响事项。

产品后台默认边界：单调用60秒、单次执行180秒、任务总期限10分钟、最多3次尝试，退避30/120秒；同任务累计6次模型调用、12次工具调用、18000个生成标记，所有修正和重试计入。执行领取需要续约和执行者校验。上述是待实现与验证的目标，不能视为当前代码已有。

产物：变体与恢复逐项结果。固定模型响应只证明程序契约，不证明真实理解。

## 第五步：小批真模型，再冻结全批

先使用实际配置模型验证工具调用和统一输出协议，最多3次预检，不支持时留下能力结论，不能偷偷换模型。只付费复验受影响的闭环和变体，最多12次调用。失败回到免费重放，不能立即再开同一大批。

小批通过后重跑记忆相关测试、全部既有必需验收、隔离双端和网络接口闭环。检索语义验收使用真实向量服务；固定向量仅验证通路。

冻结代码、提示、协议与模型配置，列出18类各3次的预期答案，运行一次最终批。每次实际模型调用完成或失败后立即落盘；样例记录理解、数据库、来源、期限、召回、澄清、调用数量、用量与错误。运行中改动冻结对象则结束本批，不拼接不同版本的成绩。

产物：冻结清单、完整原始输出、逐项独立结果、已知费用与未知开销。总分只是索引，不抵消必需项失败。

## 停止、交付与恢复

- 单任务相同检索或同错误连续重复两次且无新增信息，停止该任务；恢复上限耗尽则保留未解决状态。
- 同一阻塞经过一次有证据的修复复验仍无进展，暂停该阶段；预算耗尽、证据无法保存或实际能力不支持也立即暂停，不自动扩大预算。
- 暂停交付：已修、未修、原始证据、费用与未知项、下一步需要改变的假设。不得称“处理完成”，不得继续批跑掩盖失败。
- 全部必需项通过才能宣布本机 B 完成，更新验收报告、C 依赖门槛及 LESSONS_LEARNED.md；生产启用、部署和连续运行另验。
