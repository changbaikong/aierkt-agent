# B 记忆代理闭环执行计划

> 使用 executing-plans 与失败测试流程逐项执行；重要改动只读独立审查。当前会话已有执行授权，不提交、不推送、不部署。保留所有已有修改。

**目标：** 让代理主动查旧记录，保存忠实内容，在新会话召回并通过聊天纠正。

**架构：** 统一输出协议和来源区间；一个受限模型代理生成方案；现有存储和事务提交。旧任务与新流程互斥，判断持久化后重启复用。

## 全局约束

- 单模型调用 60 秒；执行 180 秒；任务 600 秒；最多 3 尝试，退避 30/120 秒；累计模型 6、工具 12、生成标记 18000。
- 程序不判断语义，不默认补期限；失败与真实不确定分开。C 门槛全部必需项通过前关闭。
- 免费重放先行，付费仅定向复验，最终批次先冻结；所有失败计入。
