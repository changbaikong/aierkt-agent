# 阶段 4：模型主导路由实施与验收清单

日期：2026-09-25
状态：工程实现与历史离线质量矩阵通过；新的完整矩阵和 30 回合网页验收待通过；自动回写关闭

## 目标

让主模型依据当前真实可用的能力，自主选择直接回答、具体工具、联网搜索、子代理、代码代理或后台计划。旧任务路由在 model 模式下只能生成影子记录，不能修改提示词、工具清单或执行结果。

## 固定决定

- 配置使用 `AGENT_ROUTING_MODE=legacy|model` 与 `AGENT_LEGACY_SHADOW_ENABLED`；默认 `legacy` 和开启影子记录，非法模式启动失败。
- model 模式保留明确且只读的快速路径；旧任务路由和旧意图分类器不再影响主模型。
- 代码仓库检查、修改、测试和临时脚本实验统一提交 `code.agent`；项目根目录未知时先询问，不猜路径。
- 不增加主聊天任意命令或脚本工具；不改变动作网关、审批和代码代理安全边界。
- 工程完成与阶段完成分开：实现及自动测试通过只算工程完成，新的矩阵、网页回合与人工检查通过后才算阶段完成。
