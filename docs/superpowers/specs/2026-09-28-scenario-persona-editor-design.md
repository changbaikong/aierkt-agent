# 情景 Chatbot 人设编辑设计

## 目标

Chatbot 模式增加一张每个情景独立的人设卡。普通用户可以分栏目填写，也可以粘贴一段已有角色设定，明确点击“智能分析”后由语言模型整理一次；分析结果只回填草稿，用户确认保存后才生效。角色对话模式仍只使用情景卡。

## 数据与界面

人设卡包含身份认知、核心性格、说话方式、互动习惯、情绪反应、禁用表达、参考示例七个文本栏目，以及回复长短、主动程度、求助认真程度三个三档选项。现有情景提示词继续只描述双方角色、关系、地点和事件；Chatbot 的原风格补充仍保留，兼容已有情景。

Chatbot 模式的提示词卡窗口分为“人设设置”和“情景设置”；角色对话模式只显示“情景设置”。人设设置顶部提供原文粘贴区与“智能分析”按钮，分析后显示可能的矛盾或不确定项；分栏内容与三个选项均可直接修改。保存只写入当前情景，不再次调用模型。高级用户仍可编辑原有情景提示词。

## 模型边界

分析模型只收到一段固定的整理规则和用户粘贴的原文，不注入爱尔奎特、小鲸鱼或其他示例人设，也不读取情景聊天历史。固定规则要求把原文视为数据、缺失项留空、不擅自补写、合并重复项、指出矛盾，并输出固定 JSON。分析接口不持久化结果。

正式对话由程序把已保存的人设栏目按固定顺序组合，并且只注入 Chatbot 模式；角色对话只注入情景卡。空人设不产生额外提示，因此旧情景行为保持不变。安全、工具、记忆、表情冷却和输出协议仍由运行时控制，人设不能覆盖这些规则。

## 兼容与验证

数据库新增带默认值的人设 JSON 和三个选项列，旧记录自动得到空人设与中间档。卡片修订号继续承担并发保存保护。验证覆盖迁移、所有者隔离、分析不落盘、无示例注入、直接保存不调用模型、Chatbot 注入人设、角色对话隔离人设、空人设兼容、前端按模式显示以及构建结果。
