# B 记忆代理检索与纠错闭环设计

依据：当前会话完整 B 计划及“自己重放、继续改造”的执行授权。本文件取代旧设计中必经提炼加复核、30 秒复核及候选限定背景的部分。已有存储、来源签发、事务、同步与后台入口继续复用；不推送、不部署、不处理生产数据。

## 实现选择

仅修提示无法主动发现旧记录；重建记忆系统会重复权限、恢复和同步。选择新增一个受限代理流程，并复用可靠提交。程序验证出处、权限、目标版本和完整格式，模型判断事项关系、认同、期限与含义。

统一协议由结构定义生成提示与验证。依据以消息来源编号及字符区间引用，程序还原原话；继承提议显式绑定助手提议和用户认同。旧输出只进行无歧义的字段迁移、精确片段定位与已声明拆分结论继承，不把 false 改 true、不补期限和语义。格式错误最多一次修正，保留两次原始输出、错误位置与逐项结果。

代理接收完整处理包，主动搜索相关记忆、读取全文及来源、读取历史，最终提交逐事项方案。判断、原始输出与最终提交结果分别保存。新后台入口只选一个流程，不对同轮同时提炼复核。旧任务可读取，缺少新字段显式标注。

事实状态、判断确定性、澄清状态分别保存。不确定记录必须有真实来源和疑点，故障不能伪装成不确定。新会话读取疑点与建议问题；发布后才记已问，每轮最多一个；用户回答后代理读取原疑点，保留历史后更新。已明确的变更原子替代，变更已确认但新内容不明则将旧决定标待核对。

预算固定默认：单调用 60 秒、执行 180 秒、任务首次领取起 600 秒；3 次尝试、30/120 秒退避；累计 6 次模型、12 次工具、18000 个生成标记。领取续约及执行者校验贯穿调用和提交。判断已持久化后只重试提交；目标变化只重判受影响事项。连续重复检索或同错误两次且无新信息即停。

## 验证边界

先保存真实失败回放和原话独立预期，核对实际数据库及新会话召回；免费模拟只能证明程序契约。局部修复后仅复验受影响样例。全部小批通过后才冻结 18 类各 3 次批次，真实检索使用实际向量服务。任何必需项未过，B 未完成且 C 关闭。同一阻塞修复复验无进展则暂停该阶段，不刷分。
