# 代码代理阶段 2 设计

日期：2026-09-24  
状态：已批准，设计依据为 `docs/code-agent-plan.md` 的固定架构与阶段 2 范围。

## 目标与边界

阶段 2 提供一个只能手动提交的后台代码代理。它在任务开始时复制项目到独立快照，只在快照内读取、修改和验证代码，最后返回补丁、验证结果和证据。它不得修改原项目，不得在沙箱内联网，不得执行 Git 提交、推送、发布、桌面自动化或系统设置修改。

任务类型固定为 `code.agent`。提交输入至少包含项目根目录；目标由 Work 的 `objective` 提供。代码任务使用独立并发配额，不能占满现有短任务执行槽。

## 采用方案

采用 `CompositeWorkProvider`：现有 `LocalWorkerProvider` 继续处理短任务，新建 `CodeAgentProvider` 处理 `code.agent`。组合层只按任务类型分派 `execute`、`cancel` 和 `resume`，不拥有业务状态。这样共用现有 Work 账本、事件、审批和结果回传，同时保持两类任务的执行资源与实现相互隔离。

不直接扩展 `LocalWorkerProvider`，因为代码任务是长时间、多轮、可暂停恢复的任务，会把短任务的状态机和资源配额混在一起。也不新建第二套 WorkHost，因为那会复制账本、审批、查询和事件协议。

## 任务快照

`WorkspaceSnapshotService` 为每个 Attempt 建立不可复用的任务目录。复制前验证项目根目录是允许范围内的本地普通目录，拒绝 UNC、设备路径和重解析点。复制时保留任务开始时的未提交文件内容，但排除 `.git`、密钥文件、`.env`、缓存、构建产物、虚拟环境和任务数据库；不跟随任何重解析点。

快照建立后生成基线清单，记录相对路径、文件类型、大小和 SHA-256。清单用于生成补丁、识别二进制与保护文件，并为阶段 3 的冲突检查保留稳定接口。本阶段只展示结果，不把任何变化应用到原项目。

## CodeAgentLoop

新建精简的 `CodeAgentLoop`，不复用聊天 `AgentLoop`。循环只保存模型消息、步骤数、令牌与时间预算、工具观察和审批恢复点。每轮模型只能从代码代理专用工具集中选择动作或提交最终结果；所有工具结果都必须作为结构化观察追加回模型历史。

循环终态包括：完成、失败、取消、预算耗尽和等待审批。模型声称测试通过时，结果中必须存在对应命令的成功观察；否则最终结果降级为未验证，不得把模型文字当作证据。

## 工具与动作网关

阶段 2 工具固定为：列目录、读取文本、搜索文本、写入文本、应用补丁、运行受管命令、查询当前对话范围知识、通过宿主代理搜索或读取网络资料，以及提交最终结果。文件工具只能访问当前快照；命令工具只能调用阶段 1 登记的受管运行时，并由真实 Windows 沙箱执行。

所有文件、命令、知识和网络动作都经过 `ActionGateway`。工具规格使用独立注册表并限制来源为 `code_agent`。沙箱内无网络能力；网络请求由宿主代理执行，返回经过大小、类型、重定向和私网地址限制的文本结果。

## 审批与恢复

当网关返回等待审批时，`CodeAgentLoop` 保存完整恢复点：不可修改的原始动作请求、模型消息、步骤与预算计数、快照编号和工具观察。`CodeAgentProvider` 把它翻译为 `waiting_approval`；WorkHost 原子保存检查点与审批记录。

用户批准后创建新的 Attempt，并调用 provider 的 `resume`。恢复必须从原动作请求继续，前端只能提交决定，不能替换工具名或参数。拒绝结果也要返回模型，让代理可以尝试低风险替代方案。进程重启后可恢复审批暂停，但不自动重放状态不明的命令。

## 输出与证据

完成结果包含任务摘要、统一补丁、变更文件清单、验证命令及其退出状态、限制说明和可下载工件。补丁由基线清单与当前快照比较生成；二进制变化只列元数据，不伪造文本补丁。

阶段 2 不执行自动回写。即使改动满足未来的低风险规则，也只展示补丁并明确原项目未改变。

## 失败处理

快照、AppContainer、权限、Job Object 或受管运行时不可用时失败关闭。模型或工具的临时失败在预算内允许有限重试；参数、权限、越界路径和不支持的程序属于永久失败。取消会终止当前沙箱 Job、停止模型循环并保留已产生的补丁证据。

## 测试与验收

测试分为契约、快照、组合分派、代码循环、工具边界、审批恢复、宿主网络代理和端到端八层。真实 Windows 验收必须证明：原项目未被修改；命令在 AppContainer 中运行；沙箱不能联网；文件不能越出快照；短任务与代码任务并发隔离；审批参数不可替换；补丁与实际快照差异一致。

阶段完成时运行阶段专项测试、全量测试、编译检查和补丁格式检查，并在 `LESSONS_LEARNED.md` 追加可复用经验。
